# Credit Card Fraud Detection - EDA Project

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of credit card transaction data to identify patterns in fraudulent transactions.

## 🎯 Objective
- Analyze fraud and non-fraud transactions
- Perform data cleaning
- Detect outliers
- Visualize transaction patterns

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Analysis Performed
- Data Cleaning
- Missing Value Handling
- Fraud Distribution Analysis
- Transaction Amount Analysis
- Outlier Detection using IQR
- Category-wise Fraud Analysis
- Time-based Fraud Analysis
- Correlation Heatmap

## 📈 Key Insights
- Dataset is highly imbalanced
- Fraud transactions show different transaction patterns
- Certain categories have higher fraud frequency
- Fraud activity varies across different hours
